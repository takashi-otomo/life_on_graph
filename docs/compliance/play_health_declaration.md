# Google Play ヘルスの申告 記入内容 (#44 / T-702)

Play Console「ヘルスの申告 (Health Apps Declaration)」へ登録する内容を事前に確定し、審査通過可能な状態にするための準備ドキュメント。実際の Console への入力は公開作業時に開発者が行う(本書はその入力原稿)。

> 整合性: 本申告は [データ最小化レビュー (#45)](data_minimization_review.md) の確認結果、AndroidManifest (#9) の宣言、プライバシーポリシー (#43) と完全に一致させること。

## 1. カテゴリ選択

- ☑ **Sleep management**(睡眠管理) — 睡眠ステージの可視化
- ☑ **Activity and fitness**(アクティビティとフィットネス) — 歩数・心拍の可視化

## 2. 申告する権限と利用目的 (Rationale)

| 権限 | 利用目的(申告文) |
| --- | --- |
| `READ_SLEEP` | 取得した睡眠ステージ(深い/浅い/レム/覚醒)を端末内でユーザー本人が閲覧するための可視化に使用します。クラウド送信は行いません。 |
| `READ_STEPS` | 取得した歩数を時間帯別グラフ・日次/週次/月次サマリーとして端末内で可視化するために使用します。クラウド送信は行いません。 |
| `READ_HEART_RATE` | 取得した心拍数を折れ線グラフ・安静時/最高値、および睡眠中心拍として端末内で可視化するために使用します。クラウド送信は行いません。 |
| `READ_HEALTH_DATA_HISTORY` | 初回起動時に過去30日より前のデータを遡って取得(初回バックフィル)し、過去のトレンドを表示するための一時的な利用です。継続的なバックグラウンド取得には使用しません。 |

## 3. データの取り扱い(申告の要点)

- **利用目的**: 端末内でのユーザー本人向け可視化(睡眠・歩数・心拍のグラフ表示)。
- **送信の有無**: クラウド・第三者への送信は**行わない**(ローカル完結 / オンデバイス処理)。
- **保存**: 端末内の AES-256 暗号化ローカル DB にのみ保存。鍵は Android Keystore 連携の `flutter_secure_storage` で管理。
- **共有**: 第三者提供・広告利用・分析送信は無し。
- **削除**: 設定画面から「すべてのデータを削除」でローカルデータを消去可能 (#69)。
- **履歴権限の位置づけ**: `READ_HEALTH_DATA_HISTORY` は初回バックフィル目的の一時利用であり、バックグラウンド読み取り (`READ_HEALTH_DATA_IN_BACKGROUND`) は申告・使用しない。

## 4. 申告に**含めない**もの(データ最小化)

- WRITE 系の健康権限(製品では使用しない。テスト用シーダーはデバッグビルド限定 #76)。
- `READ_HEALTH_DATA_IN_BACKGROUND`(本フェーズ対象外。後続 #48 / #49 で検討時に Prominent Disclosure と併せて再申告)。
- 体重・血糖値・呼吸数など睡眠/歩数/心拍以外のデータ種別。

> **マニフェストとの関係**: AndroidManifest には上記4つの Health Connect 権限に加えて、標準ランタイム権限 `android.permission.ACTIVITY_RECOGNITION`(身体活動アクセス, #58)が宣言されている。これは Health Connect の「ヘルスの申告」対象ではなく、通常のアプリ権限として扱う(Play のデータセーフティ/権限説明で別途扱う)。したがって「ヘルス申告の権限一覧」= Health Connect 4 権限、「マニフェストの全権限」= 4 権限 + ACTIVITY_RECOGNITION、という対応になる(矛盾なし)。詳細は [データ最小化レビュー](data_minimization_review.md)。

## 受け入れ基準の対応

- [x] Sleep management / Activity and fitness の両カテゴリを選択(本書 §1)
- [x] READ_SLEEP / READ_STEPS / READ_HEART_RATE / READ_HEALTH_DATA_HISTORY すべてに用途説明(本書 §2)
- [x] 睡眠・歩数・心拍以外の健康権限を含めない(本書 §4)
- [x] 申告の Health Connect 権限一覧が AndroidManifest の HC 宣言と一致。標準権限 ACTIVITY_RECOGNITION の扱いも明記(上記注記 / #45 レビューと整合)
- [x] 利用目的がプライバシーポリシー (#43) と整合(端末内可視化・非送信・アプリ内削除「設定→すべてのデータを削除」を反映済み)
