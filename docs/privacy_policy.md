# プライバシーポリシー — Life On Graph (LOG)

**最終更新日: 2026年6月6日**

本プライバシーポリシー（以下「本ポリシー」）は、Takashi Otomo（以下「当方」）が提供する
Android アプリ **Life On Graph（LOG）**（以下「本アプリ」）における利用者の情報の取り扱いについて
定めるものです。本アプリはヘルスケアデータを**端末内のみで処理するローカルファースト設計**を採用しており、
利用者のデータをクラウドへ送信しません。

---

## 1. 取得する情報

本アプリは、Android の **Health Connect** を通じて、利用者が明示的に許可した場合に限り、
以下の健康データを**読み取り専用（READ）**で取得します。

| データ種別 | 権限 |
| --- | --- |
| 睡眠（睡眠ステージを含む） | `READ_SLEEP` |
| 歩数 | `READ_STEPS` |
| 心拍（脈拍） | `READ_HEART_RATE` |
| 上記データの過去履歴（初回バックフィル用） | `READ_HEALTH_DATA_HISTORY` |

歩数の取得には、Android の **身体活動（Activity Recognition）** 権限を別途利用します。

本アプリは上記**以外の健康データを取得しません**。また、健康データへの**書き込み（WRITE）権限は一切要求しません**
（データ最小化の原則）。本アプリは利用者の氏名・メールアドレス・位置情報・連絡先・端末識別子などの
個人を特定する情報を収集しません。

## 2. 利用目的

取得した健康データは、**利用者本人がご自身の睡眠・歩数・心拍を可視化（グラフ表示）する目的にのみ**
利用します。これ以外の目的（分析サービスへの提供、広告、プロファイリング等）には利用しません。

## 3. データの保存と保護

- 取得したデータは、**利用者の端末内**の暗号化データベース（Hive）に保存されます。
- データベースは **AES-256** で暗号化され、暗号鍵は Android の Keystore と連携した
  セキュアストレージ（`flutter_secure_storage`）でのみ取り扱います。
- 本アプリは取得データを**外部サーバーへ送信しません**。クラウドバックアップ・同期機能は提供しません。
- 本アプリは Android の自動バックアップ（Auto Backup / クラウドバックアップ）および端末間データ転送の
  対象から本アプリのデータ（暗号化された健康データおよび暗号鍵）を**除外**しています。これにより、
  健康データが Google アカウントのバックアップ等へ複製されることはありません。
- 健康データを**ログとして平文出力しません**。

## 4. 第三者への提供・共有

当方は、法令に基づく場合を除き、取得した健康データを**第三者へ提供・共有・販売しません**。
本アプリは広告 SDK・解析 SDK を組み込んでおらず、第三者によるデータ収集は行われません。

## 5. データの保持と削除

- データは利用者の端末内にのみ保持されます。
- **アプリ内の「設定 → すべてのデータを削除」から、端末内に保存した睡眠・歩数・心拍データをいつでも削除できます。**
- **本アプリをアンインストールすると、端末内に保存された本アプリのデータは削除されます。**
- 利用者が Health Connect 側で本アプリへの権限を撤回した場合、本アプリはそれ以降の新規データ取得を停止します。
- 利用者が Health Connect 側で元データを削除した場合、**次回の同期時に本アプリの端末内複製も削除されます**。
  すぐに削除したい場合は、上記「設定 → すべてのデータを削除」または本アプリのアンインストールをご利用ください。

## 6. 利用者の権利と管理

利用者は、Android の **Health Connect アプリ**から、本アプリに付与した健康データの権限を
いつでも確認・撤回できます。権限の撤回後も、本アプリは引き続きご利用いただけます（新規データ取得は停止します）。

## 7. 子どものプライバシー

本アプリは、健康データを扱う性質上、未成年者の利用にあたっては保護者の同意のもとでのご利用を推奨します。

重要な変更を行う場合は、本ページの最終更新日を更新するとともに、必要に応じてアプリ内で通知します。
