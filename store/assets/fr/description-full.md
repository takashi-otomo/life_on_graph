# Life On Graph

Une application de santé « local-first » qui visualise votre sommeil, vos pas et votre fréquence cardiaque entièrement sur votre appareil. Vos données de santé ne sont jamais envoyées à l'extérieur.

## Fonctionnalités
- **Phases de sommeil** : profond / léger / paradoxal / éveillé sur un hypnogramme
- **Tendance des pas** : par heure et par jour / semaine / mois
- **Fréquence cardiaque** : au repos / maximale et pendant le sommeil
- **Vue intégrée** : sommeil, pas et fréquence cardiaque sur un axe temporel commun
- **Calendrier** : accédez à un jour / semaine / mois ; les jours avec données sont marqués
- **Multilingue** : français, anglais, japonais, allemand, portugais, espagnol
- **Verrouillage** : protection par biométrie / code

## Confidentialité (local-first)
- Lit uniquement le sommeil, les pas et la fréquence cardiaque depuis Health Connect, **en lecture seule**
- Stockage sur l'appareil chiffré en **AES-256**. **Aucun envoi externe**, pas de cloud, pas de SDK pub/analyse
- Supprimez toutes vos données à tout moment dans l'application

## Prérequis
- Android 8.0+ avec Health Connect
